# Readinglist-Watchlist-website_extension

This is the **RLW Frontend** built with React, Tailwind CSS, and Axios. It is the user interface for RLW, supporting search, infinite scroll, profile viewing, and post grouping.

---

## Features
✅ JWT token authentication  
✅ Search users with suggestions  
✅ Infinite scroll for posts  
✅ Group posts by date  
✅ Profile pages with user posts

---

## Quick Start
### Step 1: Clone the repository
```bash
git clone https://github.com/uranaveer/Readinglist-Watchlist-website_extension
```
### Step 2: Move into the project
```
cd Readinglist-Watchlist-website_extension
```
### Step 3: Move into the Frontend
```
cd Frontend
```
### Step 4: Install dependencies
```
npm install
npm install lucide-react
npm install axios
```
### Step 5: Add ENV variables
* Create a .env file in root Frontend directory and add `VITE_API_URL=Your_server_url`  
* Add your server base url, if you are running your server locally use http://localhost:8000/
### Step 5: Start the development server
```
npm run dev
```
