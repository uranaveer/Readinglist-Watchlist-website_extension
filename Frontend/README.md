# Readinglist-Watchlist-website_extension

This is the **RLW Frontend** built with React, Tailwind CSS, and Axios. It is the user interface for HTSI, supporting search, infinite scroll, profile viewing, and post grouping.

---

## Features
✅ JWT token authentication 
✅ Search users with suggestions  
✅ Infinite scroll for posts  
✅ Group posts by date  
✅ Profile pages with user posts

---

## Quick Start

```bash
# Clone the repository
git clone https://github.com/uranaveer/Readinglist-Watchlist-website_extension.git

# Move into the project
cd Readinglist-Watchlist-website_extension

# Move into the Fronten
cd Frontend

# Install dependencies
npm install
npm install lucide-react

# Start the development server
npm run dev
