# 🧩 Feedora – (Chrome Extension)

**Feedora** is a Chrome extension that helps you **automatically track and log the videos you watch and articles you read online**. It syncs this content to your profile in the Feedora web app, letting you build and share your reading/watchlist without lifting a finger.

---

## ✨ Features

- 📹 Automatically captures YouTube video titles and descriptions  
- 📖 Extracts text content from article pages  
- ✍️ Sends the data to your Feedora profile with one click  
- 🔐 Works only when logged in  
- 🕵️‍♂️ Includes an "Incognito" toggle to pause tracking  

---

## 🚀 How to Use

### ✅ Install the Extension
1. Clone or download this repository
2. Go to `chrome://extensions/`
3. Enable **Developer Mode**
4. Click **"Load Unpacked"** and select the `extension` folder

### ✅ Login to Your Feedora Account
1. Click the Feedora extension icon
2. Use the **Login / Sign Up** button to open the Feedora dashboard and sign in

### ✅ Start Surfing
- Visit any YouTube video or readable article page
- The extension will automatically post your content in the background

### 🕵️‍♂️ Go Incognito (Optional)
- Use the **"Go incognito"** toggle to temporarily disable content tracking
